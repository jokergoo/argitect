# argitect: Native Command-Line Argument Parsing with Rich Help Messages

A pure-R command-line argument parser that reimplements the
functionality of the Perl module `Getopt::Long` without any external
dependency, and additionally supports positional arguments. It provides
rich, customizable help messages, including one-column and two-column
styles, template-based usage text, option grouping, default-value
reporting and sub-option documentation, as well as sub-command dispatch.
